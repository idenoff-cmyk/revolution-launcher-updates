# Перевірки версії 1.1.0

Дата: 8 вересня 2026. Середовище: Windows 11 x64, Python 3.12.14, PySide6 6.10.2, PyInstaller 6.22.2.

## Автоматичні тести

**66 тестів пройдено успішно.** Перевіряються несумісні версії, Windows special paths та traversal, дублікати шляхів без урахування регістру, UUID офлайн-профілю, SHA-256, справжнє потокове HTTP-завантаження, скасування, заміна й видалення керованих файлів, збереження сторонніх файлів і світів, відкат після помилки commit, відновлення після переривання, preserve-конфігурації, збереження RAM, ізоляція інстансів, параметри API, справжній TCP status/ping протокол із контрольним локальним сервером, генерація маніфесту з реальних файлів, відхилення несумісного Modrinth-файлу та забороненого CurseForge-завантаження. Додатково перевірено відхилення процесора з ненульовим кодом завершення та зупинку дочірнього процесу при скасуванні.

```powershell
python -m pytest -q -p no:cacheprovider
```

## Інтерфейс та нативна збірка

- Перевірені всі сім сторінок і вкладки налаштувань; JavaScript-помилок не виявлено.
- Перевірені розміри 1380×900 та 1080×740; горизонтального переповнення немає.
- Через реальний QWebChannel перевірені snapshot, зміна RAM, локальний акаунт, створення та перемикання інстансу.
- PyInstaller успішно зібрав **Revolution.exe 1.1.0**. Після розблокування користувачем EXE фактично запущено: автоматичне встановлення 97 модів у чистий інстанс успішне; нативний smoke-test підтвердив QWebChannel та UI (`bridge: true`, `ui: true`). Знімок головного екрана отримано з готового EXE. EXE не має Authenticode-підпису.
- Виправлено конфлікт ICU під час пакування: Qt використовує Windows ICU; несумісна ICU з середовища збірки не постачається.
- Для UI-перевірок усередині ізольованого середовища Codex застосовано лише в тестовому процесі `QTWEBENGINE_DISABLE_SANDBOX=1`. Реліз самостійно цю змінну не встановлює; у звичайному запуску sandbox Qt збережений. Отже, цей тест не є перевіркою поведінки на всіх звичайних Windows-конфігураціях.

## Зовнішні інтеграції

- Реальний Revolution Server List Ping успішно отримував Minecraft 1.21.1, онлайн і ping. Наприклад, під час одного з вимірювань було 4/20 та 31 мс. Це спостереження в момент тесту, а не зафіксовані дані в застосунку.
- SRV для revolution.modpack.gg розпізнано; цільовий порт визначається динамічно.
- Артефакт NeoForge 21.1.250 доступний; завантаження та контрольна сума інсталятора перевірені.
- Java 21, vanilla Minecraft, ресурси, бібліотеки NeoForge та Mojang mappings фактично завантажені. Бібліотеки з Maven перевіряються за офіційним SHA-1; модпак, Java та installer — за SHA-256.
- **Запуск гри успішний поза Codex:** користувач запустив готовий EXE через окремий тестовий профіль RevolutionQA (6 ГБ, без автопідключення). Усі шість процесорів NeoForge виконані; гра стартувала о 14:49:31, ModernFix зафіксував завершення ініціалізації за 53,43 с. Після закриття отримано exit code 0 о 14:50:37. Попередня AccessDeniedException відтворювалася лише в перевіреному ізольованому запуску Codex; код офіційного інсталятора не змінювали.
- Наданий Microsoft Client ID вбудований і перевірений у snapshot налаштувань. Реальний OAuth-вхід власником ліцензійного акаунту ще не виконано.
- Реальний Discord RPC не перевірено без Application ID.
- Надані 97 JAR-файлів: CRC/SHA-256 та 393 перевірки залежностей і версії FML пройдено новим інструментом release_tool (попередній аудит без FML містив 292 правила). Перший підписаний GitHub-реліз і канал stable опубліковані та перевірені через публічні HTTPS URL. Конфігурації, RSS, карта й сайт не надані. Звіт — MODPACK.md.
- Додано 7 тестів локального комплекту: встановлення, перевірка й відновлення, пошкоджене джерело, скасування, ізоляція інстансів, пріоритет серверного маніфесту та відхилення traversal/локальних джерел у remote manifest.

## Перед публічним випуском спільноти

Запустіть Revolution.exe на звичайному Windows-профілі, встановіть модпак із комплекту, додайте потрібні серверні конфігурації та перевірте повний запуск та підключення до сервера. Microsoft Application ID уже налаштований. Для Discord Rich Presence потрібен Discord Application ID. Виконуваний файл не має Authenticode-підпису.

## Нативна перевірка комплекту 1.0.1

Перевірено фінальний Revolution.exe через реальний QWebChannel: кнопка встановлення скопіювала всі 97 JAR-файлів, статус став healthy. Після навмисного пошкодження однієї тестової копії перевірка виявила рівно одну зміну; відновлення повернуло правильний файл. Перевірені всі сім сторінок при звичайному розмірі вікна та при viewport 1080×740. JavaScript-помилок і горизонтального переповнення головного контейнера не виявлено. Окремо SHA-256 усіх 97 установлених файлів збігаються з локальним індексом. Це перевірка встановлення модпаку й інтерфейсу; результат подальшого запуску гри наведено в розділі зовнішніх інтеграцій.


## Додаткові перевірки 1.1.0

- Автоматичне перше встановлення 97 модів у чисту папку через реальний QWebChannel: успіх.
- Навмисне пошкодження одного JAR у тестовому інстансі: знайдено одну зміну; відновлення з кешу повернуло healthy.
- Сім екранів і всі п’ять вкладок налаштувань при 1380×900 / 1080×740: без горизонтального переповнення і JavaScript-помилок.
- Контрольний log із AccessDeniedException: доказова картка, приховування тестового токена й особистого шляху, відкриття звіту. Знімок екрана помічника використовує саме цей тестовий лог.
- Автотести перевіряють підроблений підпис, стару ревізію, зміну вмісту тієї самої ревізії, несумісний профіль, відсутність запису під час гри, ізоляцію інстансів, пошкоджений кеш, відсутність downgrade до комплекту та міграцію Client ID.
- Окремо перевірені рекурсивні Modrinth-залежності, конфлікт зафіксованих версій, дублікати mod ID, згода на незмінний звіт/сервіс/модель і відхилення Ollama cloud alias до надсилання логів.
- Gemini HTTP-контракт перевірений контрольними відповідями. Живі Gemini/Ollama відповіді без налаштованої моделі чи ключа не перевірялися.
- Підписаний реліз 1: 97 файлів, 393 правила, Ed25519 та SHA-256 підтверджені локально. Публікація завершена після входу власника GitHub. Всі 102 assets релізу звірені за SHA-256 із метаданими GitHub; публічний маніфест збігається з локальним. Реальний клієнт прийняв підписану ревізію 1, звірив 97 встановлених модів і повернув healthy; контрольний JAR завантажено з публічного release URL та перевірено за SHA-256.

Користувач також підтвердив відкриття головного меню Minecraft після тестового запуску готового EXE.

Окремі обмеження: реальний Microsoft OAuth, підключення до Revolution та гра у світі не перевірені. Ініціалізація клієнта та штатне завершення підтверджені журналами. В логах є попередження модів/шейдерів; exit code 0 не доводить відсутності всіх можливих конфліктів під час гри.
