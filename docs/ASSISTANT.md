# Revolution Assist

Локальний аналіз працює без мережі: Java version, залежності, heap/native memory, Mixin, OpenGL, права файлів, місце на диску, мережа й авторизація. Кожна знахідка містить рядок-доказ. За відсутності збігу причина не вигадується.

Джерела: хвости `logs/revolution-game.log`, `logs/latest.log`, журнал інсталятора, найновіший crash-report і `hs_err_pid*.log` активного інстансу. Файли до останньої спроби запуску пропускаються. Посилання за межі інстансу не читаються; звіт обмежено 64 тисячами символів.

Відомі токени, паролі, API keys, email, IPv4 та особисті шляхи приховуються. Це не гарантує видалення будь-яких приватних даних із довільного тексту моду: перед передаванням доступний точний перегляд. Експортований JSON теж очищений.

## ШІ

У `Налаштування → Помічник` обери сервіс і точну назву моделі:

- **Ollama**: локально встановлена модель, `127.0.0.1:11434`. Метадані перевіряються до надсилання логів. Cloud/remote-моделі та їхні псевдоніми відхиляються. Моделі не завантажуються автоматично.
- **Google Gemini**: власний API key із Google AI Studio і доступна цьому ключу модель. Ключ у Windows Credential Manager. Звіт надсилається Gemini API; діють умови, квоти й можливі витрати власного API-акаунту.

Натисни `Пояснити з ШІ`, переглянь звіт і підтверди конкретний сервіс. Зміна звіту, моделі чи сервісу вимагає нового перегляду. Фонових надсилань немає. Скасування під час очікування може тривати до HTTP timeout (60 секунд); уже надісланий запит відкликати неможливо.

Відповідь відображається як текст. Поради можуть помилятися; модель не має доступу до shell, зміни файлів або завантаження запропонованих нею модів.
