# Повідомлення про вразливості

Не публікуйте токени, API keys, приватні ключі підпису або логи з особистими даними. Зв’яжіться з адміністратором Revolution через Discord і погодьте приватний спосіб передавання звіту.

Маніфести перевіряються за Ed25519; SHA-256 захищає цілісність файлів. Втрата ключа підпису потребує його ротації та оновлення публічного ключа клієнтів. Моди є виконуваним кодом: підпис підтверджує схвалення адміністратором, а не відсутність усіх помилок чи небезпечної поведінки.
