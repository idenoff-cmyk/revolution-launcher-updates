# Участь у розробці

Для помилок створюй issue з версією лаунчера й очищеним звітом. Для модів додавай посилання на погоджене обговорення у Discord та точний version ID.

Зміни коду перевіряються тестами й Windows-збіркою. Зміна модпаку проходить окремий аудит залежностей і запуск на тестовому сервері; лише після цього адміністратор підписує реліз.

Не комітьте секрети, приватний ключ, світи, кеш, ігрові акаунти чи самі JAR модів. Файли релізу публікуються окремо з дотриманням ліцензій. Докладно: [UPDATES.md](docs/UPDATES.md).
